# AirBnB Listings in San Bernadino County, CA 

## Graphic Abstract
![Big Bear Area Listings](big_bear.png)

## Intro
This project entails end-to-end analysis of data collected from AirBnB listings in the San Bernadino County of California. The outline of the project is as follows:
- Data Preprocessing/Cleaning
- Database Creation and Querying (SQLite)
- Exploratory Data Analysis (Python)
- Data Visualisation (Python)
